# Metalúrgica Marinox

Primeira versão do site institucional da Metalúrgica Marinox.

## Stack

- Next.js/Vinext
- TypeScript
- Tailwind CSS
- App Router
- Shadcn/Base UI

## Scripts

- `npm run dev`: inicia a prévia local
- `npm run lint`: valida o código com oxlint
- `npm run build`: gera a build de produção

## Conteúdo provisório

As imagens em `public/marinox-assets` foram recuperadas do site público atual da própria Marinox para uso provisório. Devem ser substituídas pelos arquivos originais do cliente assim que forem fornecidos.

O site evita afirmar clientes, certificações, números, obras confirmadas, capacidade produtiva, endereço definitivo ou redes sociais quando essas informações não foram validadas no briefing.
